# Python 学习笔记

基于《Python 编程：从入门到实践（第 3 版）》（*Python Crash Course*, 3rd Edition, Eric Matthes 著）的系统学习仓库。

> 学习思路：不按书目录原序推进，而是把全书基础知识部分（第 1–11 章）**重组为 5 个阶段**，每个阶段聚焦一类核心概念，边读边写代码、边记笔记。

## 🗺️ 学习路线（5 个阶段）

### 阶段一：环境和基础变量（列表、元组）

对应第 1–4 章。搭建环境，掌握变量、字符串、数、列表、元组等最基础的数据类型。

| 章节 | 内容 | 进度 |
|---|---|---|
| 第 1 章　起步 | 安装 Python 与 VS Code、运行第一个程序、从终端运行脚本 | ☐ |
| 第 2 章　变量和简单的数据类型 | 变量命名、字符串方法、f 字符串、数、注释、Python 之禅 | ☐ |
| 第 3 章　列表简介 | 访问/修改/添加/删除元素、sort() 与 sorted()、len() | ☐ |
| 第 4 章　操作列表 | for 遍历、range()、列表推导式、切片、复制、**元组**、PEP 8 | ☐ |

关键点：索引从 0 开始；列表可变、元组不可变；避免索引错误与缩进错误。

### 阶段二：分支与循环

对应第 5、7 章。让程序学会"做判断"和"重复做事"，并能与用户交互。

| 章节 | 内容 | 进度 |
|---|---|---|
| 第 5 章　if 语句 | 条件测试、if-elif-else、布尔表达式、用 if 处理列表 | ☐ |
| 第 7 章　用户输入和 while 循环 | input()、int()、求模运算、while、break/continue、标志 | ☐ |

关键点：`==` 与 `=` 的区别；用 while 处理列表和字典；避免无限循环。

> 注：书中第 6 章（字典）调整到阶段三，与函数一起学习。

### 阶段三：高级变量（字典）与函数

对应第 6、8 章。掌握最重要的映射型数据结构，开始编写可复用的代码。

| 章节 | 内容 | 进度 |
|---|---|---|
| 第 6 章　字典 | 键值对的增删改查、get()、遍历（items/keys/values）、嵌套 | ☐ |
| 第 8 章　函数 | 位置/关键字实参、默认值、返回值、传递列表、`*args`/`**kwargs`、模块导入 | ☐ |

关键点：字典是"标签 → 值"的映射；函数修改列表 vs 传递副本；import 的几种方式。

### 阶段四：类

对应第 9 章。从"写函数"升级到"面向对象"，理解数据和行为的封装。

| 章节 | 内容 | 进度 |
|---|---|---|
| 第 9 章　类 | 创建类与实例、属性默认值、修改属性值、继承、重写父类方法、导入类、Python 标准库 | ☐ |

关键点：`__init__()` 与 `self`；子类调用父类的 `__init__()`；将实例用作属性。

### 阶段五：其它（异常等）

对应第 10、11 章。让程序更健壮：处理文件与错误、持久化数据、用测试保障质量。

| 章节 | 内容 | 进度 |
|---|---|---|
| 第 10 章　文件和异常 | 读取/写入文件、相对与绝对路径、try-except-else、静默失败、json 存储数据、重构 | ☐ |
| 第 11 章　测试代码 | 安装 pytest、单元测试、各种断言、测试类、夹具（fixture） | ☐ |

关键点：with 语句自动关闭文件；报告错误还是静默处理的取舍；测试先行的好习惯。

## 🚀 环境准备

- 编辑器：VS Code + 官方 Python 扩展
